    How it works

    1. Parse PDFs, scans and images — native text, tables, embedded figures, vector charts, OCR / VLM transcription.
    2. Index every chunk twice: BM25 (sparse) and FAISS (dense embeddings).
    3. Fuse both ranked lists with Reciprocal Rank Fusion.
    4. Rerank the candidate pool with a cross-encoder / lexical-feature reranker.
    5. Answer with an LLM constrained to numbered sources, returning citations.
